YouTube → MP3

Dán link YouTube để tải về định dạng MP3

Chrome chặn cài trực tiếp file .crx (CRX_REQUIRED_PROOF_MISSING). Vui lòng cài offline theo cách:

  • Mở chrome://extensions và bật Developer mode
  • Bấm Load unpacked và chọn thư mục extension trong dự án
  • Tùy chọn: tải file youtube-to-mp3.zip để lưu
  • Sau khi cài, mở Options của extension để nhập SERVER_BASE
